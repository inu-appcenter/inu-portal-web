## 매핑

문의 유형 칩 → 서버 `category`
- 오류 신고 `BUG_REPORT` · 기능 개선 제안 `FEATURE_SUGGESTION` · 학교 정보 오류 제보 `SCHOOL_INFO_ERROR` · 기타 의견 `ETC` · 개발진 응원 `CHEER`

상태 배지 → 서버 `status`
- 접수 `RECEIVED` · 검토 중 `IN_REVIEW` · 반영 예정 `PLANNED` · 반영 완료 `COMPLETED` · 보류 `ON_HOLD` (예정·보류는 Figma에 색 미정 — 기존 시맨틱 토큰으로)
