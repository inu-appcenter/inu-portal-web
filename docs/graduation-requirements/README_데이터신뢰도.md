# 인천대학교 졸업요건 데이터 신뢰도 안내

`inu_graduation_requirements_all66.json`에 담긴 66개 학과 데이터는 신뢰도에 따라 아래 세 그룹으로 나뉩니다. 전체 학과 목록은 [대학전체](https://www.inu.ac.kr/inu/602/subview.do) 페이지 기준이며, 코드가 겹치는 유사학과(예: 조형예술학부의 한국화전공/서양화전공, 생명과학부의 두 전공 등)는 같은 홈페이지를 공유해 동일한 규정을 적용했습니다.

이 문서는 1차 전체 작성 이후, 미확인 24개 학과(C그룹)를 대상으로 각 학과 공지사항에서 "졸업요건"·"교과과정"·"학번별 졸업요건" 등을 재검색한 2차 조사 결과까지 반영한 버전입니다.

**3차(2026-09-28)**: 개발자가 C그룹 학과 홈페이지를 직접 탐색해 찾은 자료(`new_sources_developer_found.md`)로 6개 학과를 재분류했습니다. 이 문서의 학과 코드는 수집 당시 표기이며, 앱 데이터(`src/resources/data/graduationRequirements.ts`)는 `navBarList.ts` 코드를 씁니다. 이어서 남은 C그룹 7개 학과를 같은 방식(학과 메인 → 학사정보·졸업요건·교육과정 메뉴 → 공지·자료실 제목 검색 → 첨부 PDF/HWP·이미지 판독)으로 재조사해 2개 학과를 B로 올렸습니다.

## 전공필수 과목(학과 교육과정표)
전공필수 = 전공기초 + 전공핵심(옛 교육과정표의 "전공필수" 포함)으로 보고, 학과 홈페이지 교육과정표에서 학번(입학연도)별로 뽑아 `src/resources/data/requiredMajorCourses.ts`에 생성한다. 갱신은 `node scripts/build-required-major-courses.mjs` 재실행.

- 수집 방식: 학과 사이트의 교육과정 기능 `GET https://{host}/curriculum/{siteId}/{fnctNo}/curriculumView.do?year={연도}`를 2016~올해까지 호출(페이지의 `?enc=` 쿼리는 이 경로의 base64일 뿐). 55개 학과.
- 교육과정 기능이 없는 학과는 스크립트의 `MANUAL`에 현행 교육과정만 적었다: 국어국문(PDF, 2023학번~), 바이오-로봇(2024 개정안, 2024학번~), 일본지역문화·데이터과학·스포츠과학(적용 학번 표기 없음 → 전공기초/핵심 명칭을 쓰는 2023학번~으로 적용).
- 제외: "공통" 학년 행(현장교육실습), 테크노경영(계약학과, 필수/선택 구분 없음), 자유전공·국제자유전공·융합학부(진입 학과 기준).
- IBE는 2020학번부터 교육과정표에 전공필수가 없고(전부 Major Elective) 2024학번부터 표가 없다 → 2020학번~ 빈 목록.
- 한계: 택1 과목(예: 캡스톤디자인(1)/(2) 중 택1)과 과목명 변경은 구분하지 못한다. 2016학번 이전은 교육과정표가 없어 판정하지 않는다.


## 교양 판정 기준 (기초교육원 자료)
출처: 국어국문학과 공지에 게시된 기초교육원 자료 「2026학년도 교양 교육과정표」, 「2023학년도 이후 개편된 교양 교육과정 졸업요건 관련 주요사항」, 「교양 졸업요건 주요 문의사항 FAQ」(2026.2.3.), 수강신청편람 「교양이수 졸업요건」.

- **SW 기초교양 이수 대상**(`isSwRequirementExempt`): 정보기술대학 해당 없음, 공과대학은 안전공학과·에너지화학공학과만, 도시과학대학은 도시행정학과·도시건축학부만, 생명과학기술대학은 생명공학부만, 사범대학은 수학교육과 제외. 학칙 표에는 "SW(해당학과)"로만 적혀 데이터에는 남기고 판정할 때 면제로 본다. 학과가 대체 과목을 정한 요건("SW(=전공필수 기계기초프로그래밍)")은 그대로 판정한다.
- **개편으로 이름이 바뀐 동일 교과목**: 컴퓨팅적사고와SW = AI사고와데이터리터러시, 글쓰기이론과실제 = AI시대의글쓰기이론과실제. 학번과 무관하게 서로 인정한다.
- **핵심교양**: 2019학번부터 "영역 관계없이 핵심교양(또는 2022학년도 이전 교양필수 INU핵심교양) 총 3과목". 영역 수가 아니라 과목 수이고 같은 영역 중복 이수를 인정한다(FAQ A3). 옛 성적표는 이수구분 "교양필수", 이수영역 "INU핵심창의융합"처럼 찍혀 이수영역이 "(핵심)"·"INU핵심"으로 시작하는 것으로 구분한다(전공 과목의 이수영역 "전공핵심"은 제외).
- **대학영어 ≠ 대학영어회화**: 대학영어1·2(0005058·0005059, 2학점)는 "대학영어 또는 Academic English"의 한쪽으로 2023학년도를 끝으로 개설되지 않는다. 대학영어회화1·2(0005060·0005061, 1학점)는 별도 "회화" 요건이다.
